# Moon Patches changelog

## 1.47.1 — 2026-10-12

First public Moon release, based on Morphe Patches 1.47.0.

- Nostr watch-together rooms, approved eight-digit invitations and encrypted session traffic.
- Rooms toolbar button beside Search; create and join from Home.
- Shared play/pause/seek enabled by default, including native player controls.
- SponsorBlock suspended during admission, sessions and reconnecting.
- Compact themed sheet, separate Create/Join tabs, paste/share actions, participants and collapsible host options.
- Ignore feed previews in the room lobby; prefer the visible native Search action.
- Drain the final room-close/leave event until a relay acknowledgement or a bounded timeout.
- UTF-8 Java compilation and status-text regression checks.
- Moon launcher/header/notification/themed icons, with transparent artwork and light/dark gradient wordmarks.
- Offline Moon About branding and project links, with preserved upstream credits and license notices.
- Public source metadata, GPLv3 notices, dependency credits and build/privacy/installation documentation.

Validation and limitations are recorded in [docs/validation.md](docs/validation.md). Earlier private bundles are development milestones, not public update targets. Upstream history: [Morphe v1.47.0](https://github.com/MorpheApp/morphe-patches/releases/tag/v1.47.0).
